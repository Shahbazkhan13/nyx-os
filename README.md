# NyxOS

An installable, Linux-based Cybersecurity Operating Platform.

**NOT a Kali clone.** A unified security platform with:
- 26 security domains
- Workbench SDK + Plugin SDK
- Universal Data Model + Asset Knowledge Graph
- Evidence, Finding, Risk, Correlation Engines
- Built-in Learning System + Isolated Labs
- Local AI Assistant
- Case Management + Professional Reporting
