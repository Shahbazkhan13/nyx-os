# Coding Standards

## General
- KISS: Keep It Simple
- DRY: Don't Repeat Yourself
- Every component independently testable

## Commit Messages
- feat: new feature
- fix: bug fix
- docs: documentation
- chore: maintenance
- refactor: code refactor
- test: tests
- build: build system

## Branches
- main: stable
- dev: active development
- feature/name: new features
- fix/name: bug fixes

## Security Rules (Golden Rules)
1. Never copy Kali blindly
2. Integrate mature OSS, don't rewrite
3. Every tool output -> common data model
4. Every finding has evidence
5. Every feature has documentation
6. Beginner + Professional modes
7. Local-first architecture
8. Isolated labs
9. Security from start, not patched later
10. Every component independently testable
